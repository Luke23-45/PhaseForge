## Verification methods legend

* **Unit (CPU):** `pytest tests/... -q` — synthetic tensors, no dataset/simulator.
* **Shape:** `python scripts/dev/is_shape_smoke.py` (new) asserts `(B,S)=(8,23),(B,A)=(8,7),(B,Dz)=(8,128),(B,K)=(8,6),(B,Dy)=(8,7)`.
* **Audit:** `python -m scripts.analysis.observability_audit --cache …` exit-code gate.
* **Dry-run:** `phaseforge-train … project.device=cpu train.epochs=2` / `phaseforge-sweep --dry-run`.
* **Trace:** dummy-env 5-step rollout → `trace.jsonl` schema-valid.
* **CLOUD:** full-epoch training / 50-ep robosuite rollouts — never local.
