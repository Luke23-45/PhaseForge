# Research hypothesis documents

This directory contains the paper-facing research narrative and its supporting
evidence record for the router-initialization study.

- [Final paper-facing research report](moe_routing_stability_and_decoupling_report.md)
- [Internal router-initialization evidence record](router_initialization_hypothesis.md)

The documents are based on the recorded Can/Square ablation outputs, resolved
Stage 2 configurations, runner ledger, 5-task benchmark matrix, and commanded-
action discontinuity analyses. They distinguish observed structural routing
effects from closed-loop task performance. The evidence record retains protocol
and reproducibility details; the final report presents the resulting method and
claims without development-history narration.
